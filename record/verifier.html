Verify a record

Checks a RADAR record against its path, its month's root and the published roots, and its selection against its beacon round. Everything runs in this browser, from this one file; nothing is sent anywhere. The beacon round's BLS signature is checked here too, by the same code the command line runs, compiled to WebAssembly. The time-stamp tokens' signatures need the authorities' certificates, which a browser does not hold: this page says so, and python -m record verify checks them.

Required: the .json bundle delivered with the record.
Required: roots.json, as the Bureau publishes it.
Optional: the site's bundle before this one, to check the link between them.
